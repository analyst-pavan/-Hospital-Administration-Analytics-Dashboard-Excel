# 🏥 Hospital Administration Analytics Dashboard — Excel

## 📌 Project Overview

This project presents an interactive Hospital Administration Analytics Dashboard
built in Microsoft Excel.

The objective was to transform raw hospital patient data into an interactive
reporting solution that helps users analyze patient volume, demographics,
hospital stay duration, specialization, readmissions, and geographic
distribution.

---

## 🎯 Business Problem

Hospital administrators may have large amounts of patient data but need a
simple way to answer important operational questions:

- How many patients are being handled?
- What is the average time spent in the hospital?
- Which age groups have the highest patient volume?
- How are patients distributed by gender?
- Which specializations have higher readmission volumes?
- How does patient volume vary by continent?
- Can users dynamically filter the analysis?

---

## 💡 Solution

I designed an interactive Excel dashboard that converts patient-level data
into KPI-driven visual analysis.

### Dashboard Components

- Total Patients KPI
- Average Time Spent in Hospital KPI
- Age-wise Patient Analysis
- Gender-wise Patient Analysis
- Specialization-wise Readmission Analysis
- Continent-wise Patient Distribution
- Interactive Slicers for filtering

## 📊 Key Analysis Areas

Analyzed patient distribution across different age groups,
gender categories, and continents.

### Hospital Stay
Calculated and visualized average time spent in the hospital.

### Specialization
Analyzed patient/readmission volume across medical specializations.

### Interactive Filtering
Implemented slicers so users can dynamically explore different
segments of the dataset.
